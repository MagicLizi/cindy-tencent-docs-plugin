# 腾讯文档插件（tencent-docs）

> 第三方插件，由 MagicLizi 开发维护，不是腾讯官方出品。

让 Cindy 直接读写你的腾讯文档：用自然语言查找、阅读、总结、新建和编辑在线文档、Word、Excel、幻灯片、
智能表格、思维导图与流程图，整理文件夹、知识库和分享权限，也能把电脑上的文件或网页导入腾讯文档、识别图片文字。

插件接的是腾讯文档官方开放的 MCP 服务，可用操作以腾讯文档实时提供的为准（个人版目前约 350 个）。

## 安装与更新

1. 从 [Releases](https://github.com/MagicLizi/cindy-tencent-docs-plugin/releases) 下载最新的
   `tencent-docs-<版本>.cindy`，在 Cindy 的插件页导入。安装确认会列出插件要用的权限，见下方「权限说明」。
2. 之后在插件设置页的宿主区域即可检查并安装新版本：清单里的 `githubRelease` 指向本仓库，Cindy 读取
   GitHub Release、校验附件摘要后走插件更新确认，账号、配置与数据保持不变。
3. 需要 Cindy 0.1.141 或更高版本。

## 连接账号

在 Cindy 侧边栏「插件」→「腾讯文档」详情页：

- **个人版**（QQ / 微信登录，docs.qq.com）：点「连接账号」，在浏览器里登录腾讯文档并同意授权。
- **企业版**（saas.docs.qq.com）：同样点「连接账号」，用企业账号登录。
- 两个版本可以都连；使用时 Cindy 会先问你要操作哪一个。
- **个人 Token（可选）**：腾讯文档只给一键登录的第三方应用「读」和「写」权限，删除、移动、改分享权限等
  需要「管理」权限的操作会被拒绝。在 [腾讯文档开放平台](https://docs.qq.com/open/auth/mcp.html)
  复制个人 Token，填到设置页的「个人 Token」里，插件只在这类操作被拒时用它重做一次；
  没填时 Cindy 会在需要时弹出安全输入框。请用和一键登录相同的账号获取。

所有登录凭证都由 Cindy 加密保管，只在请求腾讯文档时注入，插件代码读不到 OAuth 令牌明文；
个人 Token 只交给插件随包的 Node 进程在执行管理类操作时使用。

## 能做什么

| 场景 | 说明 |
|---|---|
| 查找与阅读 | 搜索文件、最近文件、文件夹与知识库浏览，读取正文做总结和问答 |
| 智能文档 | 用 MDX 写出带高亮块、分栏、表格、待办、图片的排版文档，适合报告、纪要、方案 |
| Word | 用 Markdown 新建，精细插入与修改文字、表格、图片、页眉页脚、批注；公文、合同、论文排版流程（个人版） |
| Excel | 批量写数据、样式、合并、冻结、筛选排序、图表、透视表 |
| 幻灯片 | 页面、形状、文字、表格、图表、动画、主题、备注、批注的增删改 |
| 智能表格 | 工作表、字段、记录、视图的批量管理 |
| 思维导图 / 流程图 | 从 Markdown / Mermaid 生成 |
| 文件与知识库 | 新建、改名、复制、移动、删除、分享权限、导出、知识库空间与目录 |
| 本机文件 | 把电脑上的 Word、Excel、PPT、PDF、CSV 等文件导入为在线文档；把 HTML 页面打包导入（个人版） |
| 图片 | 识别图片文字、把图片转成在线文档或表格（个人版，需要腾讯文档会员）；上传图片供文档使用 |
| 网页剪藏 | 把网页保存成文档 |

Word、Excel、幻灯片的编辑走腾讯文档的三个专用服务；主服务里功能较少的同名转发版会被自动替换。
插件自带一份使用手册（智能文档 MDX 写法、各品类注意事项、错误处理），Cindy 会在需要时按需读取。

## 权限说明

- **网络**：只访问 `docs.qq.com` 与 `saas.docs.qq.com`。
- **随包 Node 进程（本机权限）**：只在你要求导入本机文件、打包 HTML、识别本机图片、上传本机图片，
  或用个人 Token 执行管理类操作时启动。它会读取你指定路径的文件并上传到腾讯文档（以及腾讯文档返回的
  腾讯云存储上传地址），不读取其它文件。
- 插件隐藏了腾讯文档服务端的几项内部操作：功能缺失上报（会把你的原话发给腾讯文档）、
  技能更新检查、智能表格的 App 内部提交与界面展示。

## 不包含的部分

- 本机 Word / Excel / PPT 文件的实时编辑：这依赖腾讯文档的闭源本地编辑引擎，没有公开的分发渠道。
  本机文件请先导入为在线文档再编辑。
- 企业版没有图片文字识别、HTML 导入和 Word 专业排版流程（腾讯文档企业版本身不提供）。

## 已知限制

- 企业版的文件导入按服务端实时参数说明自动填写，作者没有企业版账号，尚未实测。
- 腾讯文档目前没有"一句话生成整份幻灯片"的公开操作，新建幻灯片需要先建空文件再逐页添加。
- 账号没有可读的身份信息，重新连接会生成新的账号记录；设置页的「重新连接」会自动移除被替换的失效账号。

## 开发与测试

```sh
node test/harness.mjs
```

测试在本机模拟个人版与企业版各 4 个 MCP 服务和上传地址，运行真实的 `main.js` 逻辑与 `node/worker.cjs`
子进程，不访问网络。打包用 Cindy 的插件制作工具（`ghost_forge_pack`）。
